# 双均线策略回测：沪深300 vs 贵州茅台

## 项目目的
实现经典双均线策略（MA5上穿MA20买入，下穿卖出），对比宽基指数与个股的策略表现。

## 策略规则
- 当5日均线上穿20日均线时，全仓买入
- 当5日均线下穿20日均线时，清仓卖出
- 手续费：万分之三；滑点：千分之一

## 回测期
2023-01-01 至 2026-08-31

## 数据来源
AKShare 免费接口（腾讯数据源），沪深300指数（sh000300）、贵州茅台（sh600519）

## 运行方式
pip install akshare pandas numpy matplotlib
python dual_ma_strategy.py

## 输出
- 交易记录 CSV
- 净值与回撤图
- 策略对比图
- 绩效指标：总收益、年化收益、波动率、最大回撤、夏普比率、胜率
