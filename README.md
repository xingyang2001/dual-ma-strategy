# 双均线策略回测：沪深300 vs 贵州茅台

## 项目目的
使用Python实现经典双均线策略（MA5上穿MA20买入，下穿卖出），对比宽基指数与个股在相同策略下的表现差异，分析趋势跟踪策略在震荡市中的局限性。

## 策略规则
- 当5日均线上穿20日均线时，全仓买入
- 当5日均线下穿20日均线时，清仓卖出
- 手续费：万分之三；滑点：千分之一

## 回测期
2023-01-01 至 2026-08-31

## 数据来源
AKShare 免费接口（腾讯数据源）
- 沪深300指数：sh000300
- 贵州茅台：sh600519

## 运行方式
pip install akshare pandas numpy matplotlib
python dual_ma_strategy.py

## 输出
- `hs300_trades.csv`、`mt_trades.csv`：交易记录
- `dual_ma_result.png`：净值与回撤图
- `dual_ma_comparison.png`：策略对比图

## 回测结果

| 标的| 总收益 | 年化收益 | 年化波动 | 最大回撤 | 夏普 | 交易次数 | 胜率 |
|------ |--------|----------|----------|----------|------|----------|------|
| 沪深300 | -8.81% | -2.49% | 12.78% | -20.04% | -0.19 | 34 | 23.5% |
| 贵州茅台 | -39.97% | -13.02% | 13.74% | -42.72% | -0.95 | 30 | 16.7% |

## 结论

**一句话总结：双均线策略在2023-2026年这段震荡市里整体失效，两个标的都是负收益。个股表现远差于宽基指数，说明单一个股风险更集中。**

**具体解读：**

1. **策略失效的原因**：双均线是趋势跟踪策略，靠的是“抓住少数大趋势，覆盖多数小亏损”。但2023-2026年中证1000和茅台都没有走出持续单边趋势，MA5和MA20频繁交叉，导致反复高买低卖。沪深300交易34次、胜率仅23.5%；茅台交易30次、胜率仅16.7%，小亏损不断累积。

2. **个股 vs 指数**：同样策略下，沪深300年化-2.49%、最大回撤-20.04%、夏普-0.19；茅台年化-13.02%、最大回撤-42.72%、夏普-0.95。茅台的波动和回撤都远大于指数，说明单一个股风险集中，没有分散效应。

3. **夏普比率**：夏普为负意味着策略承担了风险却没有获得正收益，风险调整后完全不划算。沪深300的-0.19接近零，说明亏损主要来自摩擦成本；茅台的-0.95则说明不只是成本问题，策略本身在这段行情中就是负贡献。

4. **改进方向**：
   - 加入趋势过滤（如60日均线以上才允许交易）
   - 加入止损机制，控制单笔亏损
   - 动态调整仓位，而非全仓进出
   - 做参数敏感性分析（试试10/30、20/60等组合）
   - 引入多标的组合，分散单一标的风险

## 项目局限
- 仅测试两个标的，样本有限
- 未考虑分红、停牌等实际情况
- 全仓进出，没有仓位管理
- 参数未经优化，5和20可替换
